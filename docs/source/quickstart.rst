Quick Start Guide
=================

Installation
------------

From Source
~~~~~~~~~~~

.. code-block:: bash

   git clone https://github.com/mgdavisxvs/ColorTransfer.git
   cd ColorTransfer
   pip install -e ".[all]"

With Docker
~~~~~~~~~~~

.. code-block:: bash

   docker-compose up -d
